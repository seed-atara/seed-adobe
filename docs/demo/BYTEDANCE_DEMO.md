# ByteDance Demo — 90 seconds

## Narrative

**Problem:** Generative video is powerful, but professional artists still leave the timeline, manage prompts elsewhere, download anonymous files, then manually reconstruct what happened.

**Product:** Put Seedance inside the production loop while preserving After Effects as the artist's operating system.

## Sequence

### 0–15 sec — normal AE
Open a polished real comp.
Scrub to a hero frame.

### 15–25 sec — capture
Press `Capture Frame`.
The frame appears immediately in Asset Library with AE provenance.

### 25–40 sec — direct
Prompt a camera/performance/environment change.
Attach one or more reference assets according to Seedance 2.5's verified capabilities.
Press Generate.

### 40–55 sec — generation returns
Show job state.
Result arrives as a real managed asset.
Press `Insert at Playhead`.

### 55–70 sec — iterate
Select the generated clip.
The original prompt/references/model/settings appear automatically.
Press `Variations` or modify one field.

### 70–82 sec — provenance
Open lineage/history.
Show source -> generation -> selected take -> descendants.

### 82–90 sec — close
On screen:

**Seedance isn't outside the production pipeline anymore.**
**It's inside the timeline.**

`After Effects × Seedance`
`From generative model to production infrastructure.`

## Demo safety

Have a mock/replay mode with pre-recorded provider responses and cached media. A live model call may be demonstrated separately, but the core pitch must never depend on network latency or API availability.

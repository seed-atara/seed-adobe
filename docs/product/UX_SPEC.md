# Panel UX Spec

## Top-level tabs

### GENERATE
- context/source selector
- prompt
- references
- model
- capability-dependent controls
- generate button
- active job status
- outputs

### ASSETS
- grid/list
- filter image/video/generated/captured
- search prompt/model/file
- details

### HISTORY
- parent/child lineage
- generation metadata
- recipe restore

## Generate source controls

- Current Frame
- Selected Layer (stretch)
- Asset Library
- Work Area / Clip (later)

## Result actions

- Import
- Insert at Playhead
- Regenerate
- Variation
- Branch
- Open Recipe

## UX rule

Do not expose a giant provider parameter form by default.
Show creative essentials first; advanced/provider-specific settings live in an expandable section.
